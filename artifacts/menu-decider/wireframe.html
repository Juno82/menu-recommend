Notes

"추천받기" 응답 결과를 보여주는 화면. 변종은 모두 같은 레이아웃을 공유하며, 데이터·상태만 다르다.

  • 트리거: 입력 화면 "추천받기" 또는 결과 화면 "다시 추천" / "다시 시도" 클릭
  • 인터랙션: "다시 추천" → 같은 결과 화면에서 새 메뉴로 교체 / "조건 다시 입력" → 입력 화면 / "카카오맵에서 보기" → 새 탭
  • 전환: "조건 다시 입력" → 입력 화면
  • 표시 순서: 정상 흐름에서 메뉴 카드가 식당 카드보다 먼저 화면에 나타남 (로딩 변종으로 시각 검증 가능)
  • 레이아웃: 데스크톱 식당(60%) + 지도(40% sticky) / 모바일 1열 세로 — 메뉴 → 식당 → 지도
  • S5 "이번 세션에서 본 메뉴" 표시는 "다시 추천이 이전 메뉴를 제외함"이라는 보장을 사용자에게 보여주기 위한 시각 요소
